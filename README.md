# NGOCTY NETWORK

Bản GitHub Pages 3-file.

## Chỉ cần tải lên 3 file
- `index.html` — ứng dụng chính
- `admin.html` — trang quản trị prototype
- `README.md` — hướng dẫn

Không cần `server.js`, `package.json` hay thư mục phụ.

## GitHub Pages
Vào **Settings → Pages** → chọn **Deploy from a branch** → `main` → `/ (root)` → Save.

Sau khi GitHub triển khai xong, mở đường dẫn Pages của repository. Ứng dụng chính nằm ở `index.html`.

Trang admin: thêm `/admin.html` vào cuối địa chỉ Pages.

## Lưu ý
Đây là prototype với dữ liệu nội bộ. Giá, mining reward, ranking, chat và tài sản là dữ liệu mô phỏng trong trình duyệt; không kết nối blockchain hoặc sàn giao dịch thật.
